# TREMHUB — The Redeemed Evangelical Mission Community Hub

A Progressive Web App (PWA) built with **Django 5 + Bootstrap 5**.  
Members can register, build profiles, and list/browse businesses — installable on Android & iOS.

---

## Tech Stack
- **Backend:** Python 3.10+ / Django 5
- **Frontend:** Bootstrap 5.3, Bootstrap Icons
- **Forms:** django-crispy-forms + crispy-bootstrap5
- **Images:** Pillow
- **Database:** SQLite (dev) → PostgreSQL (prod)
- **PWA:** Web App Manifest + Service Worker

---

## Setup (Step by Step)

### 1. Clone / Extract the project
```
cd tremhub/
```

### 2. Create a virtual environment
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Mac / Linux
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Run migrations
```bash
python manage.py migrate
```

### 5. Create a superuser (Admin)
```bash
python manage.py createsuperuser
```

### 6. Generate PWA icons
```bash
python generate_icons.py
```

### 7. Collect static files (optional for dev)
```bash
python manage.py collectstatic
```

### 8. Run the development server
```bash
python manage.py runserver
```

Open your browser at **http://127.0.0.1:8000**

## Install as Mobile App (PWA)

**Android (Chrome):**
1. Open the site in Chrome
2. Tap the three-dot menu → "Add to Home screen"
3. Or tap the install banner when it appears

**iOS (Safari):**
1. Open the site in Safari
2. Tap the Share button (box with arrow)
3. Tap "Add to Home Screen"
4. Tap "Add"

## Production Deployment Tips

1. Set `DEBUG = False` in `settings.py`
2. Change `SECRET_KEY` to a long random value
3. Add your domain to `ALLOWED_HOSTS`
4. Switch to PostgreSQL for `DATABASES`
5. Use **Whitenoise** or **Nginx** to serve static/media files
6. Deploy to **Railway**, **Render**, **PythonAnywhere**, or a VPS
